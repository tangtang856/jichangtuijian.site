## Quantumult X 的架构设计
Quantumult X 以强大的规则分流引擎和灵活的 JavaScript 脚本支持著称。在底部的风车图标中，用户可以自由添加 Server、Filter 与 Rewrite 远程资源。

---

## 添加节点资源标签
1. 点击右下角风车图标 → 节点「引用（订阅）」。
2. 点击右上角“+”，输入资源名称并粘贴机场订阅链接，勾选“更新前筛选”。
3. 在主界面长按小圆点可进行节点延迟排序与切换。
